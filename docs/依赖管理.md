## 2. 重要弃用与变更

| 包名 | 弃用/变更 | 推荐替代 |
|------|---------|---------|
| NumPy | np.str_/np.bool_ 类型别名已弃用 | 使用 Python 内置 str/bool |
| Pandas | DataFrame.append() 已移除 | 使用 pd.concat() |
| Pandas | DataFrame.ix 已移除 | 使用 .loc[] 或 .iloc[] |
| Seaborn | sns.distplot() 已在 v0.14 移除 | 使用 sns.displot() 或 sns.histplot() |
| Scikit-learn | load_boston() 已在 1.2 移除 | 使用 fetch_california_housing() |
| Scikit-learn | SVC(gamma='auto_deprecated') | 使用 gamma='scale' |
| SQLAlchemy | 1.x → 2.0 语法重大变更 | 使用 2.0 风格(DeclarativeBase/select()) |
| Prophet | 包名从 fbprophet 更改为 prophet | pip install prophet |
| jieba | 长期未更新但功能稳定 | 可选替代: pkuseg |
| PyTorch | torch.cuda.amp.autocast 在 ≥2.4 迁移至 torch.amp.autocast | 使用 torch.amp.autocast("cuda") |
| PyTorch | torch.cuda.is_available() 在无 GPU 环境返回 False | 运行前检测或直接安装 CPU 版本 |

## 3. 按方向安装

**全量安装：**

```bash
pip install -r requirements.txt
```

**数据获取：**

```bash
pip install requests beautifulsoup4 sqlalchemy httpx
```

**数据处理：**

```bash
pip install numpy pandas scipy scikit-learn
```

**数据可视化：**

```bash
pip install matplotlib seaborn plotly geopandas folium
```

**分析建模：**

```bash
pip install scikit-learn statsmodels prophet scipy ydata-profiling torch
```

**综合应用：**

```bash
pip install jieba wordcloud snownlp fpdf2 openpyxl nbformat
```

## 5. 常见安装问题

### prophet 安装失败

prophet 依赖 PyStan，需要 C++ 编译器。Windows 用户建议安装 [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)，安装时勾选"桌面开发 with C++"工作负载。

### ydata-profiling 与 pandas 版本冲突

ydata-profiling ≥4.0 要求 pandas≥2.0，若出现版本冲突，请先升级 pandas：

```bash
pip install --upgrade pandas
```

### jieba 首次运行慢

jieba 首次加载词典需要几秒，后续会自动缓存，无需额外处理。

### PyTorch 安装（GPU 版 vs CPU 版）

PyTorch 提供 GPU（CUDA）和 CPU 两种安装包。若需 GPU 加速，请前往 [PyTorch 官网](https://pytorch.org/get-started/locally/) 根据操作系统和 CUDA 版本选择安装命令。仅 CPU 环境可使用：

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

安装后可通过以下代码检测 GPU 可用性：

```python
import torch
print(torch.cuda.is_available())
```

### GeoPandas 安装失败

GeoPandas 依赖 GDAL、Fiona、pyproj 等 C 库，Windows 上直接 pip 安装容易失败。推荐方案：

1. 使用 conda 安装（推荐）：

```bash
conda install -c conda-forge geopandas
```

2. 或使用预编译 wheel：从 [Christoph Gohlke 的非官方轮子页面](https://www.lfd.uci.edu/~gohlke/pythonlibs/) 下载 GDAL、Fiona、pyproj 的 wheel 文件后依次安装，最后 `pip install geopandas`。
